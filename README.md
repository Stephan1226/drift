# DRIFT — 정보의 바다

끝없이 펼쳐진 빛나는 데이터의 바다를 비행하며 탐험하는, 스토리 없는 3D 서바이벌 탐험 맵.
모든 비주얼(바다 셰이더 · 데이터 입자 · 정보 모노리스 · 블룸)은 **절차적으로 생성**되며 외부 3D 에셋이 없습니다.

## 살아남기

- **Signal Integrity(시그널 무결성)** 가 시간과 함께 줄어듭니다.
- 빛나는 **데이터 코어(앰버색 비콘)** 를 모으면 신호가 회복됩니다.
- 신호가 0이 되면 `SIGNAL LOST`. 얼마나 멀리 표류했는지가 기록됩니다.

## 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 |
| `SPACE` / `SHIFT` | 상승 / 하강 |
| 마우스 | 시선 |
| `ESC` | 일시정지 (다시 클릭하면 재개) |

## 실행

브라우저의 ES 모듈 보안 정책 때문에 `file://` 직접 열기는 안 되고, 간단한 정적 서버가 필요합니다.

```bash
cd newWorld
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

또는 Node가 있다면:

```bash
npx serve .
```

Three.js r160은 importmap을 통해 CDN(jsDelivr)에서 로드되므로 최초 실행 시 인터넷 연결이 필요합니다.

## 구조

```
index.html      HUD/오버레이/스타일 + importmap
js/main.js      렌더러·포스트프로세싱·게임 루프·서바이벌 상태
js/world.js     하늘·바다·입자·모노리스·코어 절차적 생성
js/player.js    포인터락 비행 컨트롤
js/hud.js       시그널 바·스탯·위험 비네팅·레이더
js/shaders.js   GLSL (바다 / 하늘 / 입자)
```
