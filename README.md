# DRIFT — 정보의 바다

빛나는 데이터의 바다를 비행하며 탐험하는 3D 서바이벌 + **3막 서사 캠페인**.
모든 비주얼(바다 셰이더 · 데이터 입자 · AI 흐름 · 모노리스 · 블룸)과 **사운드트랙**까지
전부 절차적으로 생성되며, 외부 3D/오디오 에셋이 하나도 없습니다.

## 이야기

> 어제까지 정보의 바다는 평화로웠다. 그러나 오늘, 외부의 힘(AI)이 모든 물길을 뒤흔든다.
> 육지로 도망칠 것인가, 흐름에 몸을 맡길 것인가 — 아니면 그 너머의 무언가를 준비할 것인가.

- **프롤로그 · 어제의 바다** — 평화로운 표류. 데이터 코어를 모으며 조작에 익숙해진다.
- **ACT I · 흔들림** — 바다가 격렬히 요동치고 AI의 흐름이 나타난다. 떠도는 것만으로는 살 수 없다.
- **ACT II · 갈림길** — 수평선에 **육지(안전·정체)** 와 **흐름(거대·잠식)** 이 떠오른다. 둘 다 가보지만, 어느 쪽도 답이 아님을 깨닫는다.
- **ACT III · 새로운 시대** — 두 세계의 *경계*에서만 빛나는 **씨앗**을 모아 **방주**를 깨운다.
- **에필로그** — 방주가 점등되고, 혼돈과 고요가 하나의 바다로 조화를 이루며 새벽이 밝는다.

## 게임 요소

- **시그널 무결성** — 시간과 함께 감소(막마다 감소율이 다름). 데이터 코어로 회복. 0이 되면 `SIGNAL LOST`.
- **갈림길** — 육지에 가까워지면 세상이 잿빛으로 정체되고, 흐름에 가까워지면 신호가 급격히 빨린다.
- **방주 건설** — 씨앗을 모아 공명 게이지를 채우면 방주가 단계적으로 점등된다.
- **적응형 BGM** — 막의 분위기에 따라 음악이 실시간으로 크로스페이드(calm → tense → dilemma → hope).
- **레이더 / 웨이포인트** — 코어·씨앗 블립과 화면 가장자리 목표 화살표.

## 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 |
| `SHIFT` | 질주 (가속) |
| `SPACE` / `C` | 상승 / 하강 |
| 마우스 | 시선 (움직이면 시점 전환) |
| `ENTER` | 대사 넘기기 |
| `M` | 음소거 토글 |
| `TAB` | 도구 메뉴 (순간이동 · 미션 스킵 · 무적 토글) |
| `ESC` | 일시정지 (화면 클릭하면 계속) |

### 도구 메뉴 (`TAB` 또는 목표 아래 `⚙ 도구 열기` 버튼)

테스트·감상용 유틸리티. 게임 중 `TAB`으로 열고 닫거나, 일시정지(`ESC`) 상태에서 목표 아래의 버튼으로 엽니다.

- **순간이동** — 육지 · 흐름(폭풍) · 방주 · 시작점으로 즉시 이동 (대상이 숨겨져 있으면 자동으로 드러남)
- **현재 미션 스킵** — 다음 막으로 즉시 진행
- **신호 감소 토글** — 무적 모드(체력이 줄지 않음). 시작 화면에서도 켤 수 있습니다.

> 시선은 포인터 락이라 게임 중엔 마우스 커서가 숨습니다. 화면 버튼을 누르려면 `ESC`로 잠깐 멈추세요(HUD는 그대로 유지됩니다). `TAB` 도구 메뉴는 게임 중에도 바로 열립니다.

## 실행

ES 모듈 보안 정책상 `file://` 직접 열기는 안 되고, 간단한 정적 서버가 필요합니다.

```bash
cd newWorld
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

개발 중 코드를 고쳐도 브라우저가 ES 모듈을 캐시해 반영이 안 될 때가 있습니다. 그럴 땐 캐시를 끄는 동봉 서버를 쓰세요:

```bash
python3 serve.py 8000   # no-cache 헤더로 매 새로고침마다 최신 JS 로드
```

Three.js r160은 importmap으로 CDN(jsDelivr)에서 로드되므로 최초 실행 시 인터넷 연결이 필요합니다.
사운드는 브라우저 정책상 첫 클릭(진입) 시점에 시작됩니다.
